# Jump & Color: Interactive A-Frame Scene

Proyek ini merupakan eksperimen sederhana dalam membangun objek 3D interaktif berbasis web menggunakan [A-Frame](https://aframe.io/).  
Terdapat dua objek utama:
- Bola yang akan melompat ketika diklik  
- Kubus yang akan berubah warna ketika diklik  

Tujuan dari proyek ini adalah untuk mempelajari dasar-dasar pembuatan scene 3D, pencahayaan, animasi, serta interaksi pengguna di A-Frame.

---

## Fitur Utama
- Objek 3D interaktif yang merespons klik
- Navigasi menggunakan kombinasi **WASD** dan **mouse**
- Efek pencahayaan dasar
- Dibangun sepenuhnya menggunakan **HTML** dan **A-Frame** tanpa framework tambahan

---

## Teknologi yang Digunakan

| Teknologi | Keterangan |
|------------|-------------|
| A-Frame 1.5.0 | Framework WebXR untuk membangun konten 3D/VR di browser |
| HTML5 | Struktur utama halaman |
| JavaScript | Mengatur animasi dan logika interaksi |
